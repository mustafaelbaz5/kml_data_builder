# مراجع بيانات الحيازة

تطبيق محلي لمراجعة وإصلاح ملفات KML/KMZ الخاصة بقطع الحيازة قبل تصدير Excel.

## التشغيل

```powershell
python app.py
```

## ما يفعله التطبيق

- يقرأ KML وKMZ ويستخرج بيانات الـPolygon من العنوان والوصف وExtendedData.
- يفهم أوصاف النص العادي وHTML والفواصل العربية والإنجليزية والأسطر الجديدة.
- يكشف نقص البيانات، عدم تطابق العنوان، وتكرار IDs.
- يطبق التصحيحات الآمنة ويتيح مراجعة وتعديل الحقول يدويًا.
- يصدر KML/KMZ ملوّنًا للمراجعة في Google Earth.
- يبني Excel فقط عند معالجة جميع المشاكل المانعة.
